### [sparkles] UI V3

New redesigned UI :)

### [observe] Logs and observability

Logs now stick around for 14 days and you can search all of them, not just what the pod still has. Observe shows response times, error rates and which routes get the most traffic.

### [shield] More for databases

Save checkpoints, restore to any second, copy a database into a new one, and get a deleted database back within 30 days.
