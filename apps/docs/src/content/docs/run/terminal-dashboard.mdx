The `orchard ui` command opens an interactive dashboard in your terminal. Use it to read logs, deploy, scale, and manage databases without a browser.

## Prerequisites

- The [Orchard CLI](/cli/), installed and signed in.

## Open the dashboard

```sh
orchard ui
```

The aliases `orchard dash` and `orchard tui` run the same command.

The bottom of each screen lists the keys for that screen.

## Global keys

| Key               | Action               |
| ----------------- | -------------------- |
| `CTRL + K` or `/` | Search.              |
| `o`               | Switch organization. |

## Projects screen

| Key         | Action            |
| ----------- | ----------------- |
| `↑` and `↓` | Move.             |
| `ENTER`     | Open a project.   |
| `n`         | Create a project. |
| `r`         | Refresh.          |
| `q`         | Quit.             |

## App screen

The app screen has the tabs **Overview**, **Env**, **Deploys**, **Network**, **Storage**, **Resources**, and **Advanced**. Press `[` and `]` to change tabs.

| Tab           | Key         | Action                                 |
| ------------- | ----------- | -------------------------------------- |
| **Overview**  | `f`         | Follow logs.                           |
| **Overview**  | `b`         | Switch between build and runtime logs. |
| **Overview**  | `s`         | Open a shell.                          |
| **Overview**  | `S`         | Scale.                                 |
| **Overview**  | `+` and `-` | Change replicas.                       |
| **Overview**  | `R`         | Restart.                               |
| **Overview**  | `B`         | Rebuild.                               |
| **Overview**  | `x`         | Delete.                                |
| **Env**       | `e`         | Edit variables.                        |
| **Deploys**   | `R`         | Roll back.                             |
| **Deploys**   | `a`         | Change auto-deploy.                    |
| **Network**   | `a`         | Add a domain or port.                  |
| **Storage**   | `a`         | Add a volume.                          |
| **Storage**   | `x`         | Remove a volume.                       |
| **Resources** | `e`         | Edit requests.                         |
| **Advanced**  | `t`         | Change the update strategy.            |
| **Advanced**  | `h`         | Change the health check.               |

## Database screen

Press `←` and `→` to change tabs. Press `s` to open `psql`, and `ESC` to go back. The other keys depend on the tab.
