Preferences change how the dashboard looks and behaves. Orchard stores them in your browser, so they do not apply to other browsers or to other people.

## Change the theme

1. Go to **Account settings** > **Appearance**.
2. In **Theme**, drag the wheel to change all colors at the same time.
3. (Optional) In **Classic**, select a fixed theme from earlier versions of Orchard.
4. (Optional) Open **Advanced colours** to change individual colors.
5. To keep the theme, select **Save theme**.
6. Enter a name.

Saved themes appear in **Saved themes**.

To move a theme to another browser, select the more actions icon in **Theme**. Then select **Export** or **Import**.

## Change the interface

Go to **Account settings** > **Appearance** > **Interface**.

| Setting                         | Description                                                             |
| ------------------------------- | ----------------------------------------------------------------------- |
| **Typeface**                    | The interface font. **Hyperlegible** and **Dyslexic** are designed for readability. |
| **Project background gradient** | The animated background on project pages. Turning it off uses less GPU. |

## Change accessibility settings

Go to **Account settings** > **Accessibility**.

| Setting                 | Options                                  | Description                                                     |
| ----------------------- | ---------------------------------------- | --------------------------------------------------------------- |
| **Animation**           | **System**, **Full**, **Reduced**, **Off** | **System** follows your system's reduced motion setting.      |
| **Sound**               | On or off                                | Plays a sound when a build you are waiting on finishes.         |
| **Text size**           | **Small**, **Default**, **Large**, **Largest** | The size of text and the interface.                       |
| **Increase contrast**   | On or off                                | Uses darker text and visible borders.                           |
| **Reduce transparency** | On or off                                | Uses solid panels instead of glass and blur.                    |

## Change log timestamps

Go to **Account settings** > **Logs**.

| Setting          | Options                                  | Description                                     |
| ---------------- | ---------------------------------------- | ----------------------------------------------- |
| **Clock**        | **System**, **12 hour**, **24 hour**     | The clock format.                               |
| **Time zone**    | **Local**, **UTC**                       | **UTC** matches the times that the cluster records. |
| **Date**         | **When it changes**, **Always**, **Never** | When a log line shows its date.               |
| **Milliseconds** | On or off                                | Shows milliseconds in timestamps.               |

To read the full timestamp of a log line, hover over its timestamp.

## Try early access features

**Account settings** > **Early access** lists features that are in development. Use the switch next to a feature to turn it on or off.

The list comes from the PostHog project that the instance is configured with. If the instance has no PostHog key, the list shows `Nothing to try right now.`
