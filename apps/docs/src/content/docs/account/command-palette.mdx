The command palette searches your organization and runs common actions.

To open the command palette, press <kbd>Cmd</kbd>+<kbd>K</kbd> on macOS or <kbd>Ctrl</kbd>+<kbd>K</kbd> on other systems.

## Search

Enter text to find these resources:

- Projects
- Apps
- Databases
- Jobs

Select a result to open it.

## Actions

The command palette includes these actions:

- **New app**
- **New database**
- **New job**
- **New project**
- **Toggle dark mode**
- **Usage**
- **Invite a teammate**
- **Organization settings**
- **Account settings**
- **Copy organization ID**
- **Open docs**
- **Sign out**

## Keyboard shortcuts

| Action                        | macOS                                            |
| ----------------------------- | ------------------------------------------------ |
| Open the command palette      | <kbd>Cmd</kbd>+<kbd>K</kbd>                      |
| Toggle the sidebar            | <kbd>Cmd</kbd>+<kbd>B</kbd>                      |
| Toggle dark mode              | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd>     |
| Open the docs                 | <kbd>Cmd</kbd>+<kbd>/</kbd>                      |
| Collapse the console on an app page | <kbd>Esc</kbd>                             |

On other systems, use <kbd>Ctrl</kbd> instead of <kbd>Cmd</kbd>.
