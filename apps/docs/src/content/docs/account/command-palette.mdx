The command palette lets you reach anything in your organization without the mouse. It searches your projects, apps, databases, and jobs, and runs common actions such as creating an app or switching to dark mode.

To open the command palette, press `CMD + K` on macOS or `CTRL + K` on other systems.

## Search

Enter text to find these resources:

- Projects
- Apps
- Databases
- Jobs

Select a result to open it.

## Actions

The command palette includes these actions:

- **New app**
- **New database**
- **New job**
- **New project**
- **Toggle dark mode**
- **Usage**
- **Invite a teammate**
- **Organization settings**
- **Account settings**
- **Copy organization ID**
- **Open docs**
- **Sign out**

## Keyboard shortcuts

| Action                                   | macOS             |
| ---------------------------------------- | ----------------- |
| Open or close the command palette        | `CMD + K`         |
| Toggle the sidebar                       | `CMD + B`         |
| Toggle dark mode, in the command palette | `CMD + SHIFT + L` |
| Open the docs, in the command palette    | `CMD + /`         |
| Collapse the console on an app page      | `ESC`             |

On other systems, use `CTRL` instead of `CMD`. The dark mode and docs shortcuts work only while the command palette is open.
