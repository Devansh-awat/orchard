The command palette searches your organization and runs common actions.

To open the command palette, press `CMD + K` on macOS or `CTRL + K` on other systems.

## Search

Enter text to find these resources:

- Projects
- Apps
- Databases
- Jobs

Select a result to open it.

## Actions

The command palette includes these actions:

- **New app**
- **New database**
- **New job**
- **New project**
- **Toggle dark mode**
- **Usage**
- **Invite a teammate**
- **Organization settings**
- **Account settings**
- **Copy organization ID**
- **Open docs**
- **Sign out**

## Keyboard shortcuts

| Action                        | macOS                                            |
| ----------------------------- | ------------------------------------------------ |
| Open the command palette      | `CMD + K`                      |
| Toggle the sidebar            | `CMD + B`                      |
| Toggle dark mode              | `CMD + SHIFT + L`     |
| Open the docs                 | `CMD + /`                      |
| Collapse the console on an app page | `ESC`                             |

On other systems, use `CTRL` instead of `CMD`.
