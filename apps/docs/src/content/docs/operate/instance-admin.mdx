**Instance admin** is the area of the dashboard where superadmins manage the whole instance. Only superadmins can open it.

To open **Instance admin**, open your account menu in the sidebar, then select **Instance admin**.

The **Overview** page shows a [setup checklist](/operate/finishing-setup/) and the number of users, organizations, projects, and deployments.

## Instance

| Page              | Use it to                                                                                      | More information                                   |

| **Networking**    | Check DNS for instance hostnames and manage Cloudflare Tunnel routes.                          | [Finish instance setup](/operate/finishing-setup/) |
| **Nodes**         | Sync nodes from the cluster, and manage taints, assignments, and node pools.                   | [Manage nodes and pools](/operate/nodes/)          |

## Configuration sections

The **Configuration** page has these sections:

| Section                     | Purpose                                                                                                                                       |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **Object storage**          | Sets where Orchard writes [database backups, uploads, and cached favicons](/operate/storage/).                                                |
| **Email**                   | [Sends invitations and sign-in codes](/operate/finishing-setup/#set-up-email).                                                                |
| **Custom domains**          | Sets the hostname that people point [their own domains](/deploy/domains/#add-a-custom-domain) at with a CNAME record.                         |
| **Wildcard certificate**    | Uses [one certificate](/operate/wildcard-certificates/) for every generated app URL.                                                          |
| **Public exposure**         | Sets the [default address](/operate/finishing-setup/#set-a-default-public-ip) for raw TCP and UDP ports and public databases.                 |
| **GitLab sign-in**          | Lets people connect a GitLab account. Refer to [Deploy from GitLab, Gitea, and others](/deploy/git-providers/).                               |
| **Bitbucket sign-in**       | Lets people connect a Bitbucket Cloud account.                                                                                                |
| **Bot protection**          | Adds a Cloudflare Turnstile challenge. Refer to [Turn on bot protection](/operate/bot-protection/).                                           |
| **Model Context Protocol**  | Turns the MCP endpoint on or off. Refer to [Connect an MCP client](/mcp/).                                                                    |
| **Image scanning**          | Selects the vulnerability scanner. Refer to [Set up image scanning](/operate/image-scanning/).                                                |
| **Databases**               | Sets defaults for managed databases, such as [weekly restore tests](/data/protection/) and the [connection pooler](/data/connection-pooler/). |
| **Anonymous usage reports** | Turns usage reports on or off. Refer to [Manage anonymous usage reports](/operate/telemetry/).                                                |

A field that shows `Set by the environment` has a value from a server environment variable. Change the variable to change the value.
