Superadmins can edit and delete any user on the instance.

## Prerequisites

- You need the superadmin role.

## Edit a user

1. Go to **Instance admin** > **Users**.
2. On the user, select the edit icon.
3. Update **First name** or **Last name**. You cannot change the email address here.
4. Select **Save changes**.

## Grant or remove the superadmin role

:::caution
A superadmin can read and change every organization on the instance.
:::

1. Go to **Instance admin** > **Users**.
2. On the user, select the edit icon.
3. Turn **Super admin** on or off.
4. Select **Save changes**.

The **Users** table shows superadmins with the **Admin** badge.

## Delete a user

:::danger
This action cannot be undone. All of the user's data is permanently deleted.
:::

1. Go to **Instance admin** > **Users**.
2. On the user, select the delete icon.
3. Select **Delete**.
