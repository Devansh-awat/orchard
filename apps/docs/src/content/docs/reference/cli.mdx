The `orchard` CLI speaks the same API as the dashboard. Output is human-readable in a
terminal and JSON when piped, so your scripts get the same powers you do.

```bash
brew install --cask leafdtk/tap/orchard-cli
```

Every command accepts `-o json` for machine-readable output, and `--org` / `--env` to
override the saved context. **343 commands** are available.

## alert

### `orchard alert`

Threshold alerts on app metrics

```bash
orchard alert
```

Aliases: `alerts`

### `orchard alert create`

Add a rule: --metric cpu_percent --above 85 --for 300

```bash
orchard create
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--comparator` | string | `gt` | gt or lt |
| `--deployment` | string |  | scope to a deployment id |
| `--for` | int | `300` | seconds the condition must hold before it fires |
| `--metric` | string |  | metric id (see `orchard alert metrics`) (required) |
| `--min-request-rate` | float64 | `0` | skip evaluation below this many requests per second (traffic metrics) |
| `--project` | string |  | scope to a project id |
| `--threshold` | float64 | `0` | threshold in the metric's unit (required) |
