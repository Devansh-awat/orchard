A graft's UI module default-exports `defineGraft({ slots, screens })`. Each slot
takes a list. Mount functions get an empty element, the slot's props and the
`host` object, and return a cleanup function. `{org}` in a navigation href is
replaced with the current organization's slug.

8 slots are available.

| Slot | Contributes |
| --- | --- |
| `nav.primary` | Navigation links: `{ id, label, href, icon?, order?, visible? }` |
| `admin.nav` | Navigation links: `{ id, label, href, icon?, order?, visible? }` |
| `user.settings.tabs` | Tabs: `{ id, label, mount, order?, visible? }`, mounted with no props |
| `org.settings.tabs` | Tabs: `{ id, label, mount, order?, visible? }`, mounted with `{ orgId, orgSlug }` |
| `org.usage.tabs` | Tabs: `{ id, label, mount, order?, visible? }`, mounted with `{ orgId, orgSlug }` |
| `deployment.tabs` | Tabs: `{ id, label, mount, order?, visible? }`, mounted with `{ orgId, orgSlug, projectId, projectSlug, deploymentId }` |
| `deployment.overview.cards` | Cards: `{ id, mount, order?, visible? }`, mounted with `{ orgId, orgSlug, projectId, projectSlug, deploymentId }` |
| `project.overview.cards` | Cards: `{ id, mount, order?, visible? }`, mounted with `{ orgId, orgSlug, projectId, projectSlug }` |
