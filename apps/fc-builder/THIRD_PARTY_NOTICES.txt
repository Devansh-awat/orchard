Software shipped unmodified inside the fc-builder image

The image bundles the following programs as separate works. They are not
linked into Orchard; each keeps its own license, and its source is available
at the location given.

Firecracker and jailer v1.17.0
Project: https://github.com/firecracker-microvm/firecracker
Source for this version: https://github.com/firecracker-microvm/firecracker/tree/v1.17.0
License: Apache-2.0

Linux kernel 6.1.188 (Firecracker CI guest build)
Project: https://www.kernel.org
Source: https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tag/?h=v6.1.188
Build configuration: https://github.com/firecracker-microvm/firecracker/blob/main/resources/guest_configs/microvm-kernel-ci-x86_64-6.1.config
License: GPL-2.0-only

BuildKit v0.31.1 (buildkitd, buildctl) and runc
Project: https://github.com/moby/buildkit
Source for this version: https://github.com/moby/buildkit/tree/v0.31.1
License: Apache-2.0

Railpack v0.33.0
Project: https://github.com/railwayapp/railpack
Source for this version: https://github.com/railwayapp/railpack/tree/v0.33.0
License: MIT

Alpine Linux packages in the guest root filesystem and the host image
(busybox, musl, git, git-lfs, jq, curl, openssh-client, pigz, tini,
e2fsprogs, iproute2, iptables, ca-certificates)
Project: https://alpinelinux.org
Source: https://gitlab.alpinelinux.org/alpine/aports (per-package APKBUILD lists upstream sources)
Licenses: each package's license is recorded in its APKBUILD and in the
installed package database (/lib/apk/db/installed). Notably busybox and git
are GPL-2.0-only, musl is MIT, tini is MIT, and e2fsprogs is GPL-2.0 / LGPL-2.0.
