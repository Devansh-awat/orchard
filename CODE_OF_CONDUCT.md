# Code of conduct

Orchard is a [Hack Club](https://hackclub.com) project and follows the
[Hack Club Code of Conduct](https://hackclub.com/conduct). It applies to issues, pull requests,
discussions and anywhere else people work on Orchard together.

## Reporting

If someone's behavior concerns you, follow the reporting steps in the Code of Conduct or email
[hi@leafd.dev](mailto:hi@leafd.dev). Reports are kept confidential.
