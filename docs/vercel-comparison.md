# Orchard and Vercel: tenant-isolation comparison

Status: PARTLY SOURCED. Accessed 2026-11-08.

The rule for this page: the Vercel column may only state what Vercel's own public documentation says, with a URL. A cell that reads `not yet verified` has not been checked against an official page. Nothing here describes Vercel internals beyond what the cited page says, and the cited pages carry their own `last_updated` dates, which are given where known. Plan names (Hobby, Pro, Enterprise) are Vercel's.

The Orchard columns are accurate to `main` at `b9cc0373` and refer to the invariants I1 to I12 in `docs/tenancy-model.md`.
